# Relatórios com IA

Módulo que gera relatórios e insights a partir dos dados de estoque usando IA.

## Funcionalidades previstas
- Resumo semanal/mensal de movimentações em linguagem natural
- Previsão de demanda e sugestão de reposição
- Detecção de produtos parados e de anomalias
- Exportação dos relatórios (PDF/CSV)

## Stack sugerida
Python + API de um modelo de linguagem (LLM), consumindo os dados via backend
