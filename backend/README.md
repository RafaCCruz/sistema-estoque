# Backend

API REST do sistema de estoque.

## Responsabilidades
- Autenticação e controle de acesso
- CRUD de produtos, categorias e fornecedores
- Registro de movimentações (entrada, saída, ajuste)
- Endpoints de dados para o frontend e para o módulo de IA

## Stack sugerida
Node.js + Express (ou NestJS) + TypeScript
