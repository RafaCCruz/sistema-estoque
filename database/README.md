# Banco de dados

Modelagem e scripts do banco de dados do sistema de estoque.

## Conteúdo previsto
- Diagrama entidade-relacionamento (DER)
- Scripts de criação de tabelas (migrations)
- Dados de exemplo (seeds)

## Entidades principais
Produto, Categoria, Fornecedor, Movimentação de estoque, Usuário

## Stack sugerida
PostgreSQL
